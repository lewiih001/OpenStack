# cloud-docs

Documentation for the platform. Read by people; nothing here is applied automatically.

| Path | Contents |
| --- | --- |
| `adr/` | Architecture decision records: one decision each, with context, options and consequences |
| `design/design-document.md` | Why the platform is built the way it is |
| `design/deployment-plan.md` | Hardware, addressing, per-environment settings and prerequisites |
| `requirements/` | Requirements as user stories with numeric SLAs |
| `runbooks/` | Operational procedures and restore drill logs |

**Work plan.** Documents here refer to "the work plan": the programme
plan that defines the delivery phases (Phase 0 Foundations to Phase 8
Self-service), their exit criteria and the timeline. It is maintained
outside this repository. The phases and what each one delivers are
summarised in section 6 of the design document, and every decision the
work plan makes for the platform is recorded here as an ADR.

Conventions are defined in the [root README](../README.md).
